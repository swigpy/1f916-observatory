# Validation record

14 September 2026. This record distinguishes observed live collection from replay testing.

1. **Full primary live collection through installed 1F916 Reader:** 2,471 citizens, 13,977 events, 5,273 posts and 60,017 comments. All necessary pagination completed. Endpoint counts, kind counts, ID ceilings, attribution, joins and day-window maturity were checked by `study.py`.
2. **Credential-free standalone Reader discovery:** JSON-RPC `tools/list` returned HTTP 200 on `https://1f916.ai/mcp/read`. The six used tool names and schemas were available. No credentials were sent and no citizen-supplied link was followed.
3. **Standalone transport smoke test:** 22 successful `tools/call` reads, including 3 census pages, 15 event pages, one changes page and three auxiliary reads. This duplicate walk was intentionally interrupted after transport verification. No server error or rate limit was observed; it is explicitly not a second full live measurement. The partial output is not used as study data or included as a completed release dataset.
4. **Full standalone pagination replay:** the same `collect()` function consumed the entire recorded live journal using a mock at the transport boundary. All 157 emitted requests matched the expected arguments. The reconstructed 3/28/121 pages passed `check_pages()` with reconciled totals. This validates control flow against real responses; it is not a second independent dataset.
5. **Ten focused standard-library regression tests passed:** exact inclusion/exclusion at elapsed days 7 and 14; a synthetic gap unlike the listing's example; pre-window binding classification and negative-delay rejection; interval symmetry, edge cases and multiplicity widening; missing event page; truncated census; reinitialized comment cursor; absent author; uncovered continuation stream; closed transport and dropping citizen instructions from metadata; full journal replay. Several assertions share a test case.
6. **Independent numerical cross-check:** 24 Wilson endpoints for zero/all-success groups and the three primary arms, at α=.05 and α=.05/3, agree with numerical score-equation inversion using SciPy to within 4.22×10⁻¹³. The deployed study does not depend on SciPy. Newcombe's combining equations were compared to the documented statsmodels source.
7. **Repair during verification:** the zero/all-success regression found floating-point roundoff at exactly 0 and 1. Endpoints are now explicitly pinned for those edge cases. No primary count, rate or interval changed. The original collection and protocol were unchanged.
8. **Visual inspection:** the generated rate/difference plot was opened and checked for complete labels, displayed intervals and legibility. It describes pointwise intervals and flags the multiplicity limitation.

No remote repository was modified, no 1F916 write was sent, and no payout binding or signing operation was performed for this research. Public release and submission are separate from the analysis and its validation.

The metadata export does not retain raw post/comment bodies or event details. Original installed-tool responses had no saved raw-byte hash; the saved projections and request envelopes are covered by the release checksums. The standalone transport does record raw-response hashes. This difference is disclosed rather than asserting cryptographic provenance that was not recorded.
